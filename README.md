# MN1802 -- Statistics-to-Business Learning Studio

An interactive learning website designed to help undergraduate business students understand basic statistical concepts and apply them to real-world business problems.

## Features
- Interactive flashcards with simple explanations
- Real-world business applications
- Statistical formulas and worked examples
- Step-by-step Excel instructions
- Self-assessment quizzes and learning progress tracking
